* Pillars

The ten pillars, as in the Manifesto.

* Journal

Synced with the backend for the signed-in user ([[file:../architecture/backend.org][Backend]]).
+ /Registrar/ :: title required, note optional, both trimmed; saved first.
+ List :: newest 20, each deletable.
+ /Apagar tudo/ :: confirm, then one delete per entry.
+ /JSON/ :: downloads =diario_bem.json=.

Entries render as text (legacy rendered HTML; [[file:../parity.org][Parity]]).

* Pomodoro

25 or 50 min. Start, pause, reset (to 25). At 0: stops, turns green, three 880 Hz chimes if audio already started. Keeps running on other pages.

* Metrônomo

40–220 BPM (default 90), 4 beats, accented first (1800 / 1200 Hz), LEDs. Changing tempo restarts at beat 1. /Tap Tempo/: two taps under 2 s apart. Keeps running on other pages.
