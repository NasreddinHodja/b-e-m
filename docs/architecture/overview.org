Static SPA: SvelteKit 3, Svelte 5 runes, TypeScript strict, Tailwind 4 (no preflight), pnpm. =adapter-static= with =fallback: '404.html'=; =ssr = false= (=src/routes/+layout.ts=). The only server is Firebase, or none in dev ([[file:backend.org][Backend]]).

Pinned to the legacy page's versions: =vexflow= 4.2.2, =three= 0.128.0, =firebase= 10.8.0.

SvelteKit 3 specifics:
+ Config is in =vite.config.ts=; no =svelte.config.js=.
+ =src/lib= is =#lib= (=package.json= =imports=). Imports need =.js=; =foo.svelte.ts= is imported as =foo.svelte.js=.
+ Route IDs include the group: =resolve('/(app)/acordes')=.

The sidebar's groups, labels, icons, badges and wide views come from =NAV= (=src/lib/nav.ts=). A new view is a route plus a =NAV= entry.

* Layers

+ =src/lib/features/<view>/= :: pure =.ts= modules (tables, algorithms) and one =*.svelte.ts= class with the state and actions, exported as a singleton. Pages render it and call its methods.
+ =src/lib/session/score.svelte.ts= :: =score=, the session's scored answers. Counters, badges, histories and Intervalos' stats derive from it; =record()= saves the totals.
+ =src/lib/backend/= :: =session= and the two backends ([[file:backend.org][Backend]]).
+ =src/lib/audio/= :: =audio=, the shared synth ([[file:audio.org][Audio]]).
+ =src/lib/music/pitch.ts= :: =midiToFreq=, =pcName=, =mod12=.
+ =src/lib/ui/= :: shared components ([[file:../design/system.org][Design system]]).
+ =src/lib/i18n.svelte.ts= :: the language (below).

Imports run routes → features → session, backend, audio, music, ui. Nothing in =src/lib= imports =src/routes=.

* State

Feature state lives in module singletons, so it survives navigation, as the legacy page's hidden tabs did. So:
+ The metronome and the Pomodoro keep running on other pages.
+ The tuner keeps the microphone on until /Desligar microfone/.
+ Except Harmonia 3D: leaving stops playback and destroys the scene; the progression and camera stay.

First exercises are generated without sound. =SvelteSet= for sets, =$state.raw= for values replaced whole. Harmonia 3D's camera fields aren't reactive: the scene reads them every frame.

* Languages

Paraglide (=@inlang/paraglide-js=): =messages/pt-br.json= (base) and =messages/en.json=, compiled to =src/lib/paraglide/= (not tracked). Call =m.key()= where text is rendered.

+ Locale: the toggle's saved choice (=localStorage=), else the browser's, else Portuguese.
+ =i18n.svelte.ts= keeps it in a rune behind =getLocale()=, so the sidebar's PT / EN toggle re-renders in place: no reload, no lost state. It sets =<html lang>=.
+ State holds facts, text is made when rendered: quiz results, history =prompt= / =answer= and counterpoint issue =m= are functions.
+ Tables compared with the legacy page keep their Portuguese; =labels.ts= per feature translates them. =src/lib/i18n.test.ts= checks both catalogues match and the Portuguese labels equal the tables.
+ Not translated: LilyPond exports, developer errors, note letters, chord symbols, degrees.

* Boot and sign-in

1. The root layout calls =session.start()=; /INICIANDO SISTEMA B.E.M.../ while =loading=.
2. The backend loads by dynamic import. No auth answer in 8 s: =unreachable=.
3. =signed-out= sends =(app)= to =/login=; signing in goes to =/acordes=.

* Layout

Sidebar fixed, 220px. =main= is centred right of it: 780px, or 1320px for =wide= views (Contraponto, Harmonia 3D). Under 768px the sidebar is a drawer: hamburger, overlay, closes on navigation.

Sidebar, top to bottom: logo, totals, /zerar pontuação/ (confirm), /Sair do App/, nav with =a/b= badges on the quizzes, speaker / headphone switch, PT / EN.
