* Setup

Node 24, pnpm 12.

#+begin_src sh
git clone https://github.com/jfaragao-commits/b-e-m.git
cd b-e-m
pnpm install
pnpm dev         # localhost:5173, signed in, no Firebase
#+end_src

=pnpm install= also generates =src/lib/paraglide/= (the =prepare= script; gitignored). Dev uses the local backend; =VITE_BACKEND=firebase pnpm dev= for the real one ([[file:docs/architecture/backend.org][Backend]]). Only =esbuild= may run install scripts (=pnpm-workspace.yaml=).

* Scripts

| Command           | Does                                            |
|-------------------+-------------------------------------------------|
| =pnpm dev=        | dev server, local backend                       |
| =pnpm build=      | static build, Firebase backend                  |
| =pnpm preview=    | serve =build/=                                  |
| =pnpm check=      | type check                                      |
| =pnpm lint=       | Prettier and ESLint                             |
| =pnpm format=     | Prettier, writing                               |
| =pnpm test=       | unit and parity tests (Vitest)                  |
| =pnpm test:e2e=   | end-to-end tests (Playwright) on a build        |

=check:watch= and =test:watch= rerun on change.

* Tests

+ Unit :: =src/**/*.test.ts=, in Node. Random code runs on a seeded =Math.random= (=src/lib/testing/random.ts=).
+ Parity :: =parity.test.ts= files run =legacy/index.html='s own code (=src/lib/testing/legacy.ts=, a =vm= with a fake DOM) against the port, same inputs, same draws. A difference is a bug unless listed in [[file:docs/parity.org][Parity]].
+ End-to-end :: =e2e/=, against a local-backend build on port 4174, in =pt-BR=. Uses =/usr/bin/chromium=; set =CHROMIUM_PATH= elsewhere, or empty plus =pnpm exec playwright install chromium=.
+ CI :: [[file:.github/workflows/ci.yml][ci.yml]] runs all of it on pushes to =main= and PRs.

* Before a commit

=pnpm format=, =lint=, =check=, =test=, =build=: all pass on every commit.

* Conventions

+ 1:1 with =legacy/index.html=: a visible change, or a legacy bug fixed, is listed in [[file:docs/parity.org][Parity]]. A ported line that looks wrong gets a comment.
+ A view: a route in =src/routes/(app)/<view>/=, a =NAV= entry, logic in =src/lib/features/<view>/= (pure modules + one singleton state class). Pages only render.
+ Answers through =score.record()=, sound through =audio=, data through =session=. Firebase only in =src/lib/backend/=.
+ =#lib/...= imports with =.js=; links with =resolve('/(app)/…')=.
+ Runes only; typed props.
+ Tailwind with this repo's tokens ([[file:docs/design/system.org][Design system]]).
+ Every visible string is a message in both =messages/*.json=, rendered with =m.key()=, never stored as text.
+ Comments say why. Docs are Org, in =docs/=, updated with the code.

* Commits

[[https://www.conventionalcommits.org][Conventional Commits]]. Lowercase subject stating what's now true (=feat: the content column centred beside the sidebar=). Body with specifics, wrapped at 72. One concern per commit. No attribution lines.
