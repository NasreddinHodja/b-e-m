#+title: B.E.M — Bloco de Estudos Musicais

Ear training and music study in the browser: chords and intervals quizzes, melodic dictation, a Fux counterpoint checker, an interval ruler, diatonic harmony in 3D, a tuner, a metronome and a practice journal. The UI is in Portuguese.

SvelteKit SPA (adapter-static, =ssr = false=), Svelte 5, TypeScript, Tailwind 4, Firebase for sign-in and the journal. A 1:1 port of the original single-file app, which is kept as =index.html=, the reference the port is checked against.

#+begin_src sh
pnpm install
pnpm dev          # signed in, no Firebase; VITE_BACKEND=firebase for the real one
#+end_src
