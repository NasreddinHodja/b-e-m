#+TITLE: Contraponto (Fux)
#+OPTIONS: ^:{}

Up to three voices against a cantus firmus, 1st or 2nd species, as text or on a piano roll. Rules checked live, playback, LilyPond export. Not scored.

Files: =(app)/contraponto/+page.svelte=, =Roll.svelte=, =colors.ts=; =features/contraponto/= =rules.ts=, =lilypond.ts=, =contraponto.svelte.ts= (=contraponto=).

* Voices

Voice 0 is the cantus (1st species); others have a species and a /som/ (audible) switch. Notes: =D4=, =F#4=, =Bb3=; =r= is a rest in 2nd species. Each note has a diatonic step and a MIDI number, so spelling matters. 1st species: one note per cantus note; 2nd: two, except the last.

+ Examples :: a cantus with a correct 1st- or 2nd-species voice.
+ Species switch :: doubles or halves the notes.
+ /+ voz/ :: up to 4; starts as the cantus an octave up. /×/ removes.
+ /± compasso/ :: repeats or drops the last measure.

* Roll

Columns are half-measures, rows semitones. Shows the active voice's intervals with the cantus and rings on issues (red error, amber warning). Clicking near another voice's note selects it; dragging places notes, spelled with /Ao inserir nota/'s accidental, previewed with the cantus.

* Rules (=analyze=)

Errors unless marked warning:
+ Note count must be =n= or =2n − 1=; else nothing else is checked.
+ Rests only at the start. Voice crossing (warning).
+ No strong-beat dissonance; weak-beat dissonance only as a passing note.
+ Unison only at start and end. Start perfect; end unison or octave (fifth: warning).
+ Cadence (warnings): penultimate major sixth above or minor third below (2nd species: fifth, then that).
+ Parallel fifths/octaves and direct motion into perfects, downbeat to downbeat; a 2nd-species leap of a fourth+ in between excuses it.
+ Melody: augmented/diminished intervals, tritone, sixths (but rising minor), sevenths, leaps over an octave; chromatic step and repeated note (warnings).
+ Three notes (warnings): same note three times, two leaps one way, an uncompensated leap.
+ Range over a tenth (warning).

=pairsCheck()= checks added voices against each other for parallels. Unparseable notes give one error instead.

* Playback

All audible voices at once; a half-measure is one beat. Playhead on the roll; /repetir/ loops. /Parar/ stops the playhead, not scheduled notes (legacy).

* LilyPond

2.26, 2/2, one variable per voice, bar lines per species, bass clef for low voices. Regenerated on every note change; /Copiar/, /Salvar .ly/.
