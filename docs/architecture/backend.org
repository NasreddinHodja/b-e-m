#+TITLE: Backend
#+OPTIONS: ^:{}

One interface, =Backend= (=src/lib/backend/types.ts=): =auth=, =diario= (the journal), =stats= (score totals). Two implementations: =firebase.ts= and =local.ts=. Only =src/lib/backend/= imports Firebase.

* Which one

=kind = VITE_BACKEND ?? (DEV ? 'local' : 'firebase')= (=session.svelte.ts=).

| Command                          | Backend  |
|----------------------------------+----------|
| =pnpm dev=                       | local    |
| =VITE_BACKEND=firebase pnpm dev= | Firebase |
| =pnpm build=                     | Firebase |
| =VITE_BACKEND=local pnpm build=  | local    |

* Interface

+ =auth= :: =onChange(cb)= (now, then on every change), =signIn(email, password)= (rejects on bad credentials), =signOut()=.
+ =diario= :: =list(uid)= newest first, =add(uid, entry)=, =remove(uid, id)=.
+ =stats= :: =save(uid, stats)=.

Data:
+ =DiarioEntry= :: ={ id, titulo, obs, data, timestamp }=; =data= is a =pt-BR= date string.
+ =Stats= :: =gScoreC/W= (all), =hScoreC/W= (Acordes), =iScoreC/W= (Intervalos), =dScoreC/W= (Ditado): legacy field names.

* Session

=session= is what the app uses:
+ =status= :: =loading= → =signed-in= / =signed-out=; =unreachable= after 8 s without an answer.
+ =user=, =backend=, =start()= (idempotent), =signIn()=, =signOut()=.
+ =saveStats()= :: no-op when signed out.

Writers: =score.record()= saves the session totals after each answer (a reset doesn't save). =diario= reloads on user change, adds, removes, clears (one request per entry), exports =diario_bem.json=. Stats are never read back.

* Firebase

Modular SDK 10.8.0, project =b-e-m-2b022=. The web config is public; access is up to Firestore rules (not in this repo).

| Data    | Path                           | How                                          |
|---------+--------------------------------+----------------------------------------------|
| Journal | =users/{uid}/diario/{auto id}= | =addDoc=, =orderBy('timestamp', 'desc')=, =deleteDoc= |
| Stats   | =users/{uid}/stats/current=    | =setDoc= with =merge=                        |

E-mail and password sign-in; accounts are made in the Firebase console. Serving domains must be authorized ([[file:../guide/deploy.org][Deploying]]).

* Local

+ Starts signed in as =dev@local=. Signing out works; any credentials sign back in.
+ Journal: =localStorage['bem_dev_diario']=; stats: =localStorage['bem_dev_stats']=. Delete them to reset.
