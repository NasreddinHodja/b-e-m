#+TITLE: Intervalos
#+OPTIONS: ^:{}

Two notes play; name the interval (unison to octave). Module =i=, with per-interval hit rates.

Files: =(app)/intervalos/+page.svelte=; =features/intervalos/= =intervals.ts= (tables), =labels.ts=, =quiz.svelte.ts= (=intervalos=).

* Tables

+ =INTERVALS= :: 0–12 semitones: =symbol=, =short=, =name=, =groups= (consonant, dissonant, diatonic), =theory=.
+ =ROOTS= :: fixed A4, fixed C4, or random natural C4–B4.
+ Note names: solfège in Portuguese (=Lá=), letters in English.

* Flow

+ /Novo intervalo/ :: random active interval and root; /Aleatória/ flips the direction. Second note blurred; plays after 80 ms.
+ Playback :: /Nota 1/, /Nota 2/, /Seq./, /Harm./.
+ /Revelar resposta/ :: reveals; with /Aleatória/ the direction tag shows only when revealed.
+ /Intervalos ativos/ :: toggles (the last can't go off) and group filters. If the current interval leaves the filter, a new one is drawn. /Todos/ always lit (legacy).
+ Answer grid :: select, /Verificar/. A filter change drops marks but keeps the selection (legacy).

* Score and stats

Tag =I=, prompt =note 1 → note 2=, answer =short= or =picked → correct=. Stats: hit rate per interval answered (green ≥ 70%, gold ≥ 40%, red); at most 7 columns, kept after a reset (legacy). Then the last 30 answers.
