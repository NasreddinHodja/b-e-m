#+TITLE: Audio
#+OPTIONS: ^:{}

=audio= (=src/lib/audio/engine.svelte.ts=): one =AudioContext= for every sound but the tuner's input. Numbers in =profiles.ts=, from the legacy page.

* Context

Created on first use (so from a click), resumed if suspended. =audio.now()= is its time; =audio.started= checks without creating one.

* Graph

#+begin_example
playNote ─► master (volume) ─► low shelf ─► peak ─► high shelf ─┬─► compressor ─► out
                                                                └─► reverb ─► out
blip ─► gain ─► out                    (no EQ, no volume)
#+end_example

Compressor: −14 dB, knee 6, ratio 4, 3 ms / 150 ms. Reverb impulse: decaying stereo noise.

* Profiles

=audio.mode=: =speaker= or =headphone= (sidebar's /Caixa/ / /Fone/).

| Mode      | Low shelf    | Peak               | High shelf    | Reverb mix, length, decay |
|-----------+--------------+--------------------+---------------+---------------------------|
| speaker   | 300 Hz −8 dB | 900 Hz +5 dB Q 1.2 | 3.5 kHz +2 dB | 0.06, 0.6 s, 2.0          |
| headphone | 200 Hz +3 dB | 700 Hz +1 dB Q 0.8 | 4 kHz +1 dB   | 0.2, 1.8 s, 2.8           |

=setMode()= fades out 80 ms, rebuilds, fades back in.

* playNote(freq, t, duration?)

+ Additive sines from =PARTIALS[mode]=: 8 on speaker, 7 on headphone (with a sub-octave).
+ ADSR from =ENVELOPES[mode]=; vibrato 5.2 Hz, 1.5 or 3 cents.
+ Default length 1.6 s / 2.0 s; never shorter than the envelope.

* blip(freq, t, …)

A bare sine to the output: metronome clicks (1800 / 1200 Hz), Pomodoro chimes (880 Hz).

* Volume

=audio.volume= 0–100, default 70. Acordes' and Intervalos' sliders share it.

* Who plays what

| View        | Plays                                               |
|-------------+-----------------------------------------------------|
| Acordes     | A; the chord, 70 ms apart                           |
| Intervalos  | each note; in sequence; together                    |
| Ditado      | the melody at the form's tempo; the tonic           |
| Contraponto | every audible voice; a placed note with the cantus  |
| Régua       | reference, then the interval note                   |
| Harmonia 3D | chord tones 40 ms apart                             |
| Metrônomo, Prática | =blip=                                       |
