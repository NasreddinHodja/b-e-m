B.E.M (Bloco de Estudos Musicais): ear-training quizzes, melodic dictation, a Fux counterpoint checker, harmony in 3D, a tuner, a metronome, a practice journal. Portuguese and English. A 1:1 SvelteKit port of the single-file app in =legacy/index.html= ([[file:parity.org][Parity]]).
