#+TITLE: Ditado melódico
#+OPTIONS: ^:{}

Generate a melody or Slonimsky pattern, listen, pick its degrees from four options. The staff (VexFlow) stays blurred until you answer. Module =d=.

Files: =(app)/ditado/+page.svelte=, =Field.svelte=; =features/ditado/=:
+ =theory.ts= :: scales, spelling, key signatures.
+ =rhythm.ts= :: meters, rhythm patterns, durations.
+ =melody.ts= :: melody and Slonimsky generators, distractors.
+ =model.ts= :: pitches + rhythm → bars, playback events, LilyPond.
+ =staff.ts= :: engraving.
+ =ditado.svelte.ts= :: =ditado=.

* Form

Kept as raw strings, parsed when used (as legacy read the DOM).

05–15 are under /Parâmetros avançados/.

* Generating

1. Rhythm per bar, beat group by beat group; syncopated 4/4 and compound meters use a whole-bar pattern half the time.
2. Pitches, as offsets from the tonic (MIDI =60 + tonic=), within A2–A5:
   + Melody :: a random walk from the tonic under range, max leap, motion, focus and contour; ends on the tonic, within the max leap of the note before. Up to 600 tries.
   + Slonimsky :: the pattern repeated, transformed, fitted to the rhythm's length, moved to a random place in the range. Up to 200 tries.
   + Failure shows a hint instead of the quiz.
3. =buildModel()= splits notes at beat groups (ties), adds the key signature and metric groups (shown in /Mapa métrico/).
4. Options: the answer plus up to three with one inner note a semitone off, shuffled, shown as degrees.

* Answering

+ Pick :: scores (tag =D=), marks, unblurs, shows the degrees and rhythm.
+ /Revelar resposta/ :: unblurs and reshuffles the options; a later pick still scores (legacy).
+ /Ouvir/ :: the melody, ties merged, at the tempo. /Tônica/ :: the tonic. Both read key and tempo from the form when pressed (legacy).

* Engraving (=staff.ts=)

+ One 240px stave per bar; clef, key and time on the first; end barline on the last.
+ Notes spelled on the scale's letters; accidentals only against the signature.
+ Dots as modifiers in a non-strict voice; beams per beat group; ties.
+ The SVG is cropped to the drawing and centred on the paper.
+ A failing element is skipped; a failing staff shows its error.

* LilyPond

Collapsed block, slides open. Its =<pre>= is empty (legacy; TODO). /Copiar .ly/, /Baixar .ly/: LilyPond 2.24 with key, meter, ties, tempo.

* Kept on purpose

+ Within a beat group, notes sort by pitch, not time, so staff and playback can differ from the answer.
+ =nameAt()= relies on JS =%= keeping the sign.
