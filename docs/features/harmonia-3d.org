#+TITLE: Harmonia 3D
#+OPTIONS: ^:{}

Diatonic chords as three.js blocks whose legs are stacked thirds, laid along a time axis. Build a progression, play it, orbit. Not scored.

Files: =(app)/harmonia-3d/+page.svelte=; =features/harmonia3d/= =fields.ts= (tables, spelling), =harmonia.svelte.ts= (=harmonia=), =scene.ts= (=HarmoniaScene=).

* Model

+ =FIELDS= :: major and natural minor: roman numerals, 12 tonics, 7 degrees as thirds =v= (root→3rd), =h= (3rd→5th), =s= (5th→7th), triad and seventh names, the dominant.
+ Block :: X = root→3rd (down), Y = 3rd→5th (across), the 7th a third leg down. Z = time, one unit per beat.
+ Colours :: dominant red, major green, minor gold, diminished ivory.

* Flow

+ Major / minor :: switches to the relative key.
+ Triads / sevenths :: the third leg grows or shrinks.
+ A degree button :: plays it, appends it (max 16), highlights it 1.5 s.
+ Next chord length :: 1, 2 or 4 beats.
+ Presets :: five progressions; editing switches to /Personalizada/.
+ Play :: the scene's frame loop plays each chord as it's reached, moves a playhead; tempo changes keep the beat.
+ Views :: front, diagonal (default), side, top.
+ Sizes :: semitone labels on the legs.

* Scene

+ Loaded with dynamic =import()= on mount; destroyed on leave (stops playback). WebGL or load failure shows a message.
+ Geometry rebuilt when =harmonia.dirty=; old objects disposed.
+ Labels are HTML spans projected each frame.
+ Drag orbits, Shift/right-drag pans, wheel/pinch zooms.
+ Camera fields live on =harmonia= (not reactive), so the view returns as left.
