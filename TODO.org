Vitest runs 72 tests in Node (=pnpm test=). The unit tests cover the pure modules: pitch, chords, Ditado's theory, rhythm, melody, model and LilyPond, the counterpoint rules and LilyPond, Harmonia 3D's spelling and colours, pitch detection. Drawing code runs on a seeded =Math.random=.

CI (=.github/workflows/ci.yml=) runs all of it on pushes and PRs; it hasn't run on GitHub yet.

Not covered: the UI flows and the audio compared against the legacy page (only the logic is), and real Firebase.

** Done
+ commit =0e08b7f=

Paraglide (=@inlang/paraglide-js=), the owner's pick. 547 messages in =messages/pt-br.json= and =messages/en.json=. The locale is the toggle's saved choice, else the browser's language, else Portuguese; it's resolved in the browser (the app is an SPA, so no per-language URLs or server hooks). =src/lib/i18n.svelte.ts= keeps it in a rune and overrides Paraglide's =getLocale()= with it, so the PT / EN toggle at the bottom of the sidebar re-renders every message in place: no reload, the quiz and the score survive (an end-to-end test checks it). =<html lang>= follows.

To make that work, state holds facts and the text is made when rendered: quiz outcomes, the score history's prompt and answer (functions), the counterpoint issues (functions), the tuner's reading, the Pomodoro's status, Ditado's hints. Tables the parity tests compare with the legacy page keep their Portuguese and are shown through a =labels.ts= per feature; a test checks that in Portuguese those read exactly as the tables, and that both catalogues have the same keys and parameters.

Not translated, on purpose: LilyPond exports, developer-facing errors, note letters, chord symbols and degrees. In English the notes are letter names (=A → E=), in Portuguese solfège (=Lá → Mi=), as before.
