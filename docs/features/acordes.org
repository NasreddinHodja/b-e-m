#+TITLE: Acordes
#+OPTIONS: ^:{}

A triad plays against A; name the chord, then what A is in it. Module =h=.

Files: =(app)/acordes/+page.svelte=; =features/acordes/= =chords.ts= (tables), =labels.ts= (translated labels), =quiz.svelte.ts= (=acordes=).

* Tables

+ =QUIZ_CHORDS= :: 9 major, 9 minor: those where A has a named function. =root= (MIDI 60–71), =type=, =intervals=, =aFunc=.
+ =TEACHER_CHORDS= :: all 12 roots per quality; =aFunc= =—= where A has none.
+ =FUNCS= :: answer symbols by semitones above the root (=1= … =7=); =FUNC_NAMES= in words.

* Flow

+ /Novo acorde aleatório/ :: draws from /Sortear/'s pool, resets, blurs, plays after 80 ms.
+ /Octave/ :: moves A (and the chord) to octave 3, 4 or 5.
+ /Revelar acorde/ :: shows name, notes and /A = …/ (always laid out, so no height change).
+ /Qual acorde está tocando?/ :: first click answers: marks, reveal, feedback. Grid always 3 rows. Switching /Maior/ / /Menor/ / /Ambos/ drops the marks (legacy).
+ /Qual função o A exerce?/ :: select, then /Verificar função/.
+ /Modo professor/ :: first panel, collapsed (open, it shows the loaded chord). Loads any chord, unscored.
