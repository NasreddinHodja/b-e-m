#+TITLE: Design system
#+OPTIONS: ^:{}

The legacy look: near-black surfaces, ivory text, gold labels, film grain. Tailwind 4 utilities on the components; tokens and global rules in =src/routes/layout.css=.

* No preflight

Only Tailwind's theme and utilities layers are imported; the base layer has the legacy reset (=* { box-sizing: border-box; margin: 0; padding: 0 }=), because preflight broke parity. So:
+ Buttons keep the browser's border and background unless a class sets them (=border-0=, =bg-transparent=).
+ Lists keep bullets unless =list-none=.
+ Form controls get =font-family: inherit= in the base layer.

* Tokens

Tailwind's defaults are cleared: only these exist (=text-gray-500= compiles to nothing).

+ Colours :: =bg= #0c0c0c, =surface= #141414, =surface-2= #1c1c1c, =well= #080808, =line= #2a2a2a, =line-lt= #333, =fg= #e4e0d8, =fg-soft= #c9c5bc, =fg-mid= #888, =fg-faint= #444, =accent= #e4e0d8, =green= #4a9e6a, =red= #b84848, =gold= #c8a030, =blue= #7a9bc8, =paper= #f2eddf, =logo= #e8e2d4, =white=, =black=, =transparent=. Also CSS variables (=var(--color-gold)=).
+ Fonts :: =font-sans= Inter (body), =font-mono= DM Mono, =font-serif= Playfair Display, =font-display= Barlow Condensed. All SIL OFL, from Google Fonts (=src/app.html=).
+ Type :: =3xs= 8px, =2xs= 9, =xs= 10, =sm= 11, =base= 12, =md= 13 (body), =lg= 15. Bigger sizes inline (=text-[54px]=).
+ Animations :: =animate-fade-up= (panels), =animate-regua-pulse=.

Mono is for data only: note entry, LilyPond, degree strings, symbol answer grids, Harmonia's degree buttons, the tuner's readouts, the roll's labels, history rows. Everything else is Inter.

* Global rules

Reset, body (flex row, Inter 13px), grain (=body::after=, 3.5% noise), pointer cursor on buttons and selects, dark =select=, flat range slider, 4px scrollbar.

Answer-state utilities, =!important= so they beat a button's colours: =state-selected= (gold), =state-correct= (green), =state-wrong= (red). =markClass()= (=src/lib/ui/types.ts=) picks one.

* Components (=src/lib/ui/=)

+ =Panel= :: section surface; =label=, =labelExtra= snippet, =padding=, =class=.
+ =PanelLabel= :: tiny uppercase label with a rule.
+ =Btn= :: outlined or =primary=; fill slides up on hover; =pad=.
+ =TabBtn= :: toggle; =active=.
+ =CheckBtn= :: full-width check button.
+ =RevealBtn= :: small reveal toggle.
+ =Feedback= :: answer result box; slides open (220 ms, instant with reduced motion).
+ =HistoryList= :: scored answers; =showTag=.
+ =OptsRow=, =OptsLabel= :: control row and its label.
+ =BemLogo= :: the round mark.

=class=, =pad= and =padding= props replace defaults.

* Icons

Lucide (=@lucide/svelte=), one import per icon. 16px in buttons and nav, 14px in small buttons and chevrons, 13px in the sidebar footer. Hidden from screen readers by default; icon-only buttons get =aria-label=. Musical symbols in content stay text.

* Conventions

+ Classes as =class={[...]}= arrays; long lists in a =const=.
+ To beat a component's utility, use the =!= suffix (=mt-0!=).
+ Transforms whose order matters are written whole: =[transform:scale(1.5)]=.
+ Arbitrary values are normal (legacy sizes); use the scale when it matches.
+ =pnpm format= sorts classes (=prettier-plugin-tailwindcss=).

* Breakpoints

+ under 768px: sidebar drawer.
+ under 900px: Contraponto's columns stack.
+ under 1100px: Harmonia's side panel goes below; stage 520px.
+ under 500 / 480px: teacher grid 4 columns; Ditado form 1 column.
