#+TITLE: Audio
#+OPTIONS: ^:{}

Every sound but the tuner's input comes from =audio= (=src/lib/audio/engine.svelte.ts=), one =AudioContext= for the whole app. Its numbers are in =src/lib/audio/profiles.ts=, copied from the legacy page.

* The context

=audio.ctx= creates the context on first use and resumes it if suspended, so the first sound comes from a click, as browsers require. =audio.now()= is =ctx.currentTime= (creating the context); =audio.started= says whether one exists without creating it (the Pomodoro chime checks it, as the legacy one did).

* Signal graph

#+begin_example
note voices ──► master gain ──► low shelf ──► peaking ──► high shelf ──┬──► compressor ──► destination
 (playNote)     (volume/100)                                           └──► convolver ──► reverb gain ──► destination

blip ──► its gain ──► destination        (no EQ, no volume)
#+end_example

The compressor is fixed: threshold −14 dB, knee 6, ratio 4, attack 3 ms, release 150 ms. The convolver's impulse is generated: stereo noise decaying as =(1 − i/len)^decay= over =reverbDur= seconds.

* Output profiles

=audio.mode= is =speaker= or =headphone= (the sidebar's /Caixa/ and /Fone/ buttons). Each mode has its own EQ, reverb, partials, envelope and vibrato:

| Mode      | Low shelf     | Peak               | High shelf    | Reverb mix, length, decay |
|-----------+---------------+--------------------+---------------+---------------------------|
| speaker   | 300 Hz −8 dB  | 900 Hz +5 dB Q 1.2 | 3.5 kHz +2 dB | 0.06, 0.6 s, 2.0          |
| headphone | 200 Hz +3 dB  | 700 Hz +1 dB Q 0.8 | 4 kHz +1 dB   | 0.2, 1.8 s, 2.8           |

=setMode()= ramps the master to 0 over 80 ms, rebuilds the graph for the new profile 100 ms later, and ramps back to the volume over 80 ms. Before any sound has played it only sets =mode=.

* playNote

=audio.playNote(freq, t, duration?)= schedules one note at context time =t=:

+ Additive sines, one per entry of =PARTIALS[mode]= (gain, frequency factor, detune in cents): speaker has 8 (harmonics 1–4 and detuned pairs on 1 and 2), headphone 7 (with a sub-octave at 0.5).
+ An ADSR on the note's gain from =ENVELOPES[mode]= (speaker: attack 8 ms, peak 0.42, decay 120 ms, sustain 0.26, release 350 ms; headphone: 22 ms, 0.36, 180 ms, 0.24, 500 ms).
+ Vibrato: one LFO at 5.2 Hz into every partial's frequency, 1.5 cents deep on speaker, 3 on headphone.
+ The length is =duration=, or the profile's default (1.6 s speaker, 2.0 s headphone), never shorter than attack + decay + release + 60 ms. Oscillators stop 150 ms after the envelope ends.

* blip

=audio.blip(freq, t, { peak, attack?, decayEnd, stopAt })= is a bare sine straight to the destination, bypassing the EQ and the volume slider: the metronome's click (1800 Hz on the downbeat, 1200 Hz otherwise) and the Pomodoro's three 880 Hz chimes.

* Volume

=audio.volume= (0–100, default 70) is the master gain. The /Vol/ sliders on Acordes and Intervalos both bind to it, so they move together.

* Who plays what

| View        | Calls                                                                         |
|-------------+-------------------------------------------------------------------------------|
| Acordes     | A alone; the chord arpeggiated 70 ms apart, 2.2 s each                        |
| Intervalos  | each note; the two in sequence (1.6 s, second at +1.7 s); both together, 2.2 s |
| Ditado      | the melody at the form's tempo, each note 90% of its value (at least 120 ms); the tonic, 1.5 s |
| Contraponto | every audible voice from one start time; a placed note and the cantus under it, 0.6 s |
| Régua       | reference note then interval note, 1.2 s each, 1.3 s apart                    |
| Harmonia 3D | each chord's tones 40 ms apart                                                |
| Metrônomo   | =blip=                                                                        |
| Prática     | =blip= (the Pomodoro's end)                                                   |

The tuner opens its own =AudioContext= for the microphone ([[file:../features/afinador.org][Afinador]]).
