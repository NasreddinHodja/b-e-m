#+title: B.E.M — Bloco de Estudos Musicais

Ear training in the browser: chord and interval quizzes, melodic dictation, a Fux counterpoint checker, an interval ruler, harmony in 3D, a tuner, a metronome, a practice journal. Portuguese and English.

SvelteKit SPA, Svelte 5, TypeScript, Tailwind 4, Firebase. A 1:1 port of the original single-file app, kept in =legacy/index.html= as the reference.

#+begin_src sh
pnpm install
pnpm dev          # signed in, no Firebase
#+end_src
