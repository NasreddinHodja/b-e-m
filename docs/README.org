B.E.M (Bloco de Estudos Musicais) is a music-education SPA: ear-training quizzes, a melodic dictation generator, a Fux counterpoint checker, a 3D view of diatonic harmony, a tuner, a metronome and a practice journal. The UI is in Portuguese. It was a single =index.html=; it is now SvelteKit, ported 1:1 from that file, which stays in the repo as the reference ([[file:parity.org][Parity]]).
