* Rule

The app is a 1:1 port of the legacy single-page app, bugs included. Structure may change; behaviour, output and look may not, except the deviation and the changes below. A bug found while porting is ported, then listed; fixing it is a later, recorded change.

* Reference

=legacy/index.html=: the legacy app, one 4,314-line file, unformatted (=.prettierignore=), not served.

Its library versions, pinned exactly in =package.json=:

| Library  | Legacy                                     | Port              |
|----------+--------------------------------------------+-------------------|
| VexFlow  | jsdelivr =vexflow@4.2.2= (line 8)          | =vexflow= 4.2.2   |
| three.js | cdnjs =r128=, loaded on demand (line 3825) | =three= 0.128.0   |
| Firebase | gstatic =10.8.0= modules (lines 685–687)   | =firebase= 10.8.0 |

* Deviation

+ Journal entries render as text. Legacy put them in =innerHTML= (line 2190), so HTML in them rendered. Open decision.

* Changes since the port

+ Layout :: content centred right of the sidebar (legacy: against it).
+ Acordes :: the /A = …/ badge always takes its space; the chord grid is always 3 rows; /Modo professor/ is first and collapsed.
+ Quizzes :: feedback slides open and closed.
+ Ditado :: staff cropped and centred on its paper; /ouça e adivinhe/ on a dark chip; the LilyPond block slides open.
+ Ditado :: the leap into the final tonic is checked from the note before it (legacy: from the note it replaced, so it could exceed /Salto máx./).
+ Languages :: Portuguese and English, with a toggle. Portuguese is the legacy text.
+ Fonts :: Inter for text; DM Mono (legacy's only font) for data.
+ Icons :: Lucide in place of Unicode and emoji glyphs.

* Kept on purpose

Legacy behaviour that looks wrong, ported as is; a comment marks each. *To ask the owner: bug or intended?* (=notes.org=, "Meeting with the owner").

+ Acordes :: switching the guess pool drops its marks.
+ Intervalos :: /Todos/ always lit. A filter change drops marks and highlight but keeps the selection. Direction-tag toggling as legacy (=directionShown=). Stats keep their last column count after a reset (=statCols=).
+ Ditado :: within a beat group, notes sort by pitch, not time (legacy line 2897). /Ouvir/, /Tônica/ and the export read key and tempo from the form when pressed. The LilyPond =<pre>= is empty. Dots are modifiers on undotted notes. Only =groups= reaches =Beam.generateBeams= (the other legacy options were camelCase, ignored by VexFlow 4). Engraving errors are skipped per element. A pick after /Revelar resposta/ scores.
+ Contraponto :: /Parar/ doesn't silence notes already scheduled.
+ Afinador :: the mic stays on across pages; =latency: 0= is passed; reference A isn't clamped.
+ Prática :: /Apagar tudo/ stays red on hover. The Pomodoro chime needs audio already started.
+ Layout :: the Afinador's panels have no gap between them.
+ Stats are written, never read back: each session starts at zero.

* How it's checked

+ Parity tests, 2026-10-25 to 2026-10-26: the port's logic run against the legacy code, same inputs, same random draws (Ditado, Contraponto, Harmonia 3D, shared tables, pitch detection). No difference but the final-leap fix. Deleted once the port was done; in git history before the commit that removed them.
+ Unit and end-to-end tests (=pnpm test=, =pnpm test:e2e=): the app's own logic and flows. They don't compare with legacy.
+ 2026-10-25, screenshots against legacy at 1280×900 and 390px: 9 of 12 views pixel-identical on load; Acordes, Intervalos and Ditado differ only in random content. Scripts not in the repo.

Not checked: UI flows and audio against legacy, real Firebase, browsers other than Chromium. The flows to run by hand: [[file:flows.org][Flows]].
