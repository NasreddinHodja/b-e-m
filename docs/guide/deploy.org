#+TITLE: Deploying
#+OPTIONS: ^:{}

=pnpm build= writes a static =build/=. Any host works if it answers unknown paths with =404.html= (the SPA fallback).

* GitHub Pages

=.github/workflows/deploy.yml=, on push to =main=: install, build with =BASE_PATH= from =configure-pages=, upload, deploy. Only the deploy job can write.

Settings → Pages → Source must be /GitHub Actions/. On 2026-10-25 =jfaragao-commits/b-e-m= published the =main= branch root instead (=gh api …/pages=: =build_type: legacy=); changing it needs repo admin.

Deep links work: Pages serves =404.html=, the app routes.

* Base path

=BASE_PATH= sets =paths.base= in builds (empty in dev). Unset for a domain root; =/sub/path= otherwise.

* Firebase

Builds use Firebase (unless =VITE_BACKEND=local=). Every serving domain (=jfaragao-commits.github.io=, custom, preview) must be in Authentication → Settings → Authorized domains, or sign-in fails. If Firebase doesn't answer in 8 s, the app says so.
